# Liberty Wave

Музыкальный виджет **Liberty Wave** поверх окон для Windows 10/11, со своей чёрно-серебристой иконкой в `.exe`, окне, трее и расширении. Красные акценты, подпись **Liberty**, сплошная внешняя волна, обложка и управление воспроизведением.

## Скачать и запустить

В [GitHub Releases](https://github.com/dyushaboldyusha-a11y/music-adapter/releases/latest) скачайте Windows `.exe` последнего опубликованного релиза. Это переносимое приложение: Node.js на пользовательском компьютере не нужен. Файл не подписан сертификатом издателя. Начиная с 0.4.0 имя файла — `Liberty-Wave-0.4.0-Windows.exe`; настройки, бинды и подключения браузера из прежнего Music Adapter сохраняются.

Откройте свой плеер, включите трек и запустите виджет. По умолчанию **Ctrl+Shift+8** переключает управление и закрепление, **Ctrl+Shift+Пробел** ставит музыку на паузу и продолжает воспроизведение. NumPad не требуется. В управляемом режиме перетаскивайте за обложку или название. В закреплённом режиме клики проходят сквозь окно, кнопки не реагируют на наведение, не получают фокус и не показывают подсказки; горячая клавиша музыки продолжает работать.

В меню **«…» → «Горячие клавиши…»** нажмите на нужное сочетание, задайте своё и сохраните. Можно использовать F-клавишу или сочетание с Ctrl, Alt, Shift, Win. При русской раскладке буквы определяются по физическим клавишам. Esc отменяет запись, кнопка × отключает только бинд музыки. Во время настройки глобальные бинды приостанавливаются. При конфликте прежняя настройка сохраняется; после отмены рабочие бинды восстанавливаются. Настройки доступны также через правый клик по значку в трее, даже если клавиша недоступна. Num8 при включённом NumLock остаётся дополнительной клавишей управления, пока выбран стандартный Ctrl+Shift+8.

Внизу расположен выбор источника. В режиме **«Автоматически»** выбирается активный воспроизводящий плеер. Выбранное вручную приложение или вкладка остаётся целью команд; после закрытия источника виджет не переключает управление на чужой плеер. Чтобы снова выбирать автоматически, вернитесь к первому пункту списка.

## Поддерживаемые источники

| Источник | Подключение |
| --- | --- |
| Яндекс Музыка, установленное приложение | Системная медиасессия Windows |
| Spotify, установленное приложение | Системная медиасессия Windows |
| SoundCloud как установленный клиент или PWA | Системная медиасессия, если этот клиент её предоставляет; отдельного официального Windows-клиента виджет не устанавливает |
| Яндекс Музыка, Spotify, SoundCloud, YouTube / YouTube Music, VK Музыка в браузере | Расширение Liberty Wave для выбора конкретного сервиса и вкладки |
| Chrome, Edge, Яндекс Браузер, Firefox, Brave, Opera, Vivaldi без расширения | Доступные системные медиасессии браузера, если браузер их публикует; Windows обычно не раскрывает название сайта |

Пароли и токены музыкальных сервисов не нужны. В аккаунты входите в обычном приложении или на сайте. Виджет не использует Spotify Web API и не изменяет установленные плееры.

Приложение читает Windows GSMTC. Поэтому доступность обложки, перемотки, предыдущего/следующего трека, перемешивания и повтора зависит от плеера. Недоступные кнопки скрываются. Лайки через GSMTC не предоставляются, сердечка нет. Ошибки не выводятся баннером поверх виджета. Для живого эфира шкала не предлагает фиктивную перемотку, а для длинных видео время отображается с часами.

## Подключить музыкальные вкладки

1. Скачайте из того же релиза архив `Liberty-Wave-Browser-Connector-<версия>.zip` и распакуйте в постоянную папку.
2. В Chrome, Edge или Яндекс Браузере откройте страницу расширений, включите режим разработчика и выберите **«Загрузить распакованное расширение»**, указав папку с `manifest.json`.
3. В виджете включите управление своей горячей клавишей (по умолчанию Ctrl+Shift+8) → меню **«…» → «Подключить браузер»** (или кнопку `＋` возле списка источников).
4. Введите восьмизначный код в окне расширения. Код действует пять минут; соединение затем запоминается на этом компьютере.
5. Обновите уже открытые музыкальные вкладки и включите трек. Они появятся в списке с названием сервиса, браузера и трека.

Расширение рассчитано на актуальные браузеры Chromium 111+. Его Firefox-сборки пока нет; Firefox можно использовать через доступную системную медиасессию Windows. Управление сайтами использует Media Session и доступные элементы аудио/видеоплеера. Набор функций зависит от версии сайта. Перемешивание и повтор через расширение пока не предлагаются; в приложениях эти кнопки видны, если их поддерживает системная сессия.

Расширение связывается только с локальным виджетом. Доступ к содержимому страниц ограничен перечисленными музыкальными сервисами. Обложки запрашиваются с перечисленных CDN без cookies. Разорвать связь можно в окне расширения или через **«Отключить все браузеры»** в меню виджета. Подробности — [browser-extension/README.md](browser-extension/README.md).

## Синхронизация времени и VK

В 0.3.1 обновите **и виджет, и расширение**, затем перезагрузите музыкальные вкладки. Повторные сообщения больше не перезапускают отсчёт от старой позиции. Время привязано к моменту измерения в плеере; пауза, скорость воспроизведения и настоящая перемотка обрабатываются отдельно. При потере свежих измерений виджет прекращает предсказывать позицию, вместо бесконечного ухода вперёд.

Для VK расширение дополнительно видит `Audio`, созданные вне DOM, и использует доступный интерфейс веб-плеера VK как запасной адаптер. Поэтому при текстовой Media Session можно получить длительность, позицию, обложку и команды от самого плеера. Набор функций всё ещё зависит от конкретной версии сайта; тесты воспроизводят этот сценарий в Chromium, а не входят в живой аккаунт VK.

## Внешний вид

- Масштаб **50–175%** — меню «…» либо **Ctrl + колесо** при включённом управлении.
- **«…» → «Цвет интерфейса…»** — цветовой круг, яркость, готовые цвета и HEX. Выбор сразу виден на кнопках, волне, рамке, фоне, надписях и панелях настроек. «Сохранить» запоминает тему, «Отмена» возвращает прежнюю. Изображение обложки сохраняет свои цвета.
- Непрозрачность оформления **25–100%**. Кнопки, название, исполнитель и шкала остаются чёткими.
- Размер и положение запоминаются; при смене разрешения или DPI виджет возвращается в видимую область. На маленьком экране временно уменьшается, после возврата разрешения восстанавливает выбранный масштаб.
- Меню трея позволяет вернуть виджет в угол экрана и закрыть приложение.

## CS2, игры и 4:3

Используется обычное прозрачное окно Electron с `alwaysOnTop`. Оно предназначено для обычных окон и безрамочных игр. Эксклюзивный fullscreen, защищённые экраны Windows и экран блокировки не поддерживаются.

Для CS2 используйте **«В окне без рамки»**. Если нужно растянутое 4:3, предварительно выставьте такое же разрешение рабочего стола Windows (например, 1280×960, если поддерживается), а растягивание настройте в видеодрайвере. Виджет не внедряется в процессы игр. В самой CS2 сборка не проверялась.

## Разработка и проверки

Node.js 24.5+, npm; нативный медиамост требует Windows 10 1809+ / Windows 11 и Windows PowerShell 5.1.

```sh
npm ci
npm start
npm run demo
npm test
npm run test:settings
npm run check:windows
npm run dist:win
npm run check:branding
```

Демо явно обозначено и не выдаёт образцы за реальное подключение. В нём можно просматривать интерфейс всех источников; демонстрационная обложка — собственная иллюстрация.

Проверки с настоящим Chromium и расширением:

```sh
npx playwright install chromium
npm run test:browser
```

Для Linux GUI нужен Xvfb. В подготовленной облачной среде:

```sh
PATH=/workspace/.music-adapter-tools/x11/usr/bin:$PATH npm run test:gui
PATH=/workspace/.music-adapter-tools/x11/usr/bin:$PATH xvfb-run -a -s '-screen 0 1440x1000x24 -nolisten tcp' npm run test:settings
PATH=/workspace/.music-adapter-tools/x11/usr/bin:$PATH xvfb-run -a -s '-screen 0 1440x1000x24 -nolisten tcp' npm run test:browser
```

CI проверяет маршрутизацию источников, авторизацию локального моста, отсутствие реакции мыши в закреплённом режиме, настоящий WinRT-поток обложки и полный обмен Chromium MV3 ↔ Electron. Проверка настроек включает настоящие глобальные клавиши при фокусе другого приложения, паузу браузерного VK при закреплённом виджете, конфликты, палитру и сохранение между запусками. На Linux для клавиш используется X11/XTest и Python 3; на Windows — системный ввод. Браузерные проверки работают на контролируемых страницах пяти сервисов с реальными API браузера; это не проверка живых аккаунтов или каждой текущей версии сайтов. Проверка `check:branding` читает ресурсы обоих Windows `.exe`: название продукта и встроенную иконку нескольких размеров. Сборка Windows и публикация `.exe`, архива расширения и SHA-256 выполняются GitHub Actions.
