# Liberty Wave

## Скачать и запустить

В [GitHub Releases](https://github.com/dyushaboldyusha-a11y/music-adapter/releases/latest) скачайте Windows `.exe` последнего опубликованного релиза. Это переносимое приложение: Node.js на пользовательском компьютере не нужен. Файл не подписан сертификатом издателя. Имя файла — `Liberty-Wave-<версия>-Windows.exe`; настройки, бинды и подключения браузера из прежнего Music Adapter сохраняются.

Откройте свой плеер, включите трек и запустите виджет. По умолчанию **Ctrl+Shift+8** переключает управление и закрепление, **Ctrl+Shift+Пробел** ставит музыку на паузу и продолжает воспроизведение. NumPad не требуется. В управляемом режиме перетаскивайте за обложку или название. В закреплённом режиме клики проходят сквозь окно, кнопки не реагируют на наведение, не получают фокус и не показывают подсказки; горячая клавиша музыки продолжает работать.

При запуске открывается отдельное окно **Liberty Wave** с разделами «Мой виджет», «Источники», «Внешний вид», «Горячие клавиши» и «Обновления». Все настройки находятся в нём. Открыть его повторно можно кнопкой в правом верхнем углу виджета, нажатием на значок в трее или повторным запуском .exe. Закрытие окна скрывает его; виджет продолжает работать. Для выхода нажмите «Завершить работу» в приложении.

В разделе **«Горячие клавиши»** выберите действие, нажмите своё сочетание и сохраните. Бинды приостанавливаются на время записи; при уходе из окна рабочие клавиши восстанавливаются. При конфликте прежние сочетания сохраняются. Esc отменяет запись, кнопка × отключает музыкальный бинд. Поддерживаются обычные клавиши, F-клавиши и сочетания с Ctrl, Alt, Shift, Win. При русской раскладке буквы определяются по физическим клавишам. Num8 остаётся дополнительной клавишей, пока выбран стандартный Ctrl+Shift+8.

В разделе **«Источники»** выберите приложение или вкладку. «Автоматически» выбирает воспроизводящий плеер. После закрытия вручную выбранного источника команды не переходят в чужой плеер. Здесь же находятся создание кода подключения, копирование кода, скачивание расширения и отключение браузеров.

## Возможности 0.5.0

**Громкость:** ползунок и кнопка отключения звука находятся под кнопками воспроизведения. В разделе «Горячие клавиши» можно назначить увеличение/уменьшение на 5%, отключение звука и переключение компактного режима. Новые бинды изначально пустые; старые сохраняются. Бинды работают и при закреплённом виджете.

Установленные приложения регулируются через их аудиосессии Windows на устройстве вывода по умолчанию: точное имя исполняемого файла или AUMID сопоставляется с выбранным плеером. Общая громкость Windows и другие программы не изменяются. Если Windows не позволяет найти аудиосессию этого приложения, регулятор скрывается. Для вкладок обновите расширение до **0.5.0**, нажмите «Обновить» на странице расширений и перезагрузите музыкальные страницы: громкость меняется у доступного аудио/видеоэлемента или через поддерживаемый плеер VK. Если сайт не предоставляет доступ к громкости, неработающие кнопки не появляются. Без расширения системная медиасессия браузера не предоставляет регулировку отдельной вкладки.

**Компактный режим:** переключатель в разделе «Мой виджет» или свой бинд превращают карточку в небольшую полоску с обложкой, названием, исполнителем, предыдущим/следующим треком, паузой, прогрессом и громкостью. Положение полного и компактного вида сохраняется отдельно. Масштаб задаётся в разделе «Внешний вид». Открытие приложения и подключение браузера не меняют положение, размер или режим виджета.

**Волна и свечение:** в разделе «Внешний вид» выбирайте реакцию на звук, плавную декоративную волну или выключение. Интенсивность регулируется от 0 до 100%; экономичный режим снижает частоту с 30 до 12 кадров/с. В режиме реакции читается пиковый уровень **всего звука устройства вывода Windows по умолчанию**, включая другие слышимые приложения. Микрофон не используется, аудиозапись не создаётся. В тишине или при потере устройства волна затухает; при отсутствии аудиоданных пульсация не имитируется. Контур непрерывный, маска оставляет его снаружи карточки. Системная настройка уменьшения движения останавливает анимацию. На других ОС доступна декоративная волна.

## Обновления внутри приложения

В новом приложении откройте раздел **«Обновления»**, нажмите **«Проверить» → «Скачать» → «Установить и перезапустить»**. Обновление берётся из официального GitHub-репозитория; перед установкой проверяется SHA-256. Переносимый `.exe` заменяется по прежнему пути: ярлыки, бинды, цвет и подключённые браузеры сохраняются. Музыкальный плеер продолжает работать; перезапускается только виджет. Папка приложения должна разрешать запись текущему пользователю.

Для перехода с **0.5.0 и старше** один раз скачайте новую версию вручную, закройте Liberty Wave и замените `.exe`. В 0.4.1–0.5.0 загрузчик ошибочно отменял перенаправления GitHub при нажатии «Скачать», сообщая об отсутствии подключения. Это исправлено в **0.5.1**; последующие обновления можно устанавливать из приложения. Настройки и бинды сохраняются. Для регулировки громкости вкладок требуется расширение 0.5.0 или новее.

## Поддерживаемые источники

| Источник | Подключение |
| --- | --- |
| Яндекс Музыка, установленное приложение | Системная медиасессия Windows |
| Spotify, установленное приложение | Системная медиасессия Windows |
| SoundCloud как установленный клиент или PWA | Системная медиасессия, если этот клиент её предоставляет; отдельного официального Windows-клиента виджет не устанавливает |
| Яндекс Музыка, Spotify, SoundCloud, YouTube / YouTube Music, VK Музыка в браузере | Расширение Liberty Wave для выбора конкретного сервиса и вкладки |
| Chrome, Edge, Яндекс Браузер, Firefox, Brave, Opera, Vivaldi без расширения | Доступные системные медиасессии браузера, если браузер их публикует; Windows обычно не раскрывает название сайта |

Пароли и токены музыкальных сервисов не нужны. В аккаунты входите в обычном приложении или на сайте. Виджет не использует Spotify Web API и не изменяет установленные плееры.

Приложение читает Windows GSMTC. Поэтому доступность обложки, перемотки, предыдущего/следующего трека, перемешивания и повтора зависит от плеера. Недоступные кнопки скрываются. Лайки через GSMTC не предоставляются, сердечка нет. Ошибки не выводятся баннером поверх виджета. Для живого эфира шкала не предлагает фиктивную перемотку, а для длинных видео время отображается с часами.

## Подключить музыкальные вкладки

1. Скачайте из того же релиза архив `Liberty-Wave-Browser-Connector-<версия>.zip` и распакуйте в постоянную папку.
2. В Chrome, Edge или Яндекс Браузере откройте страницу расширений, включите режим разработчика и выберите **«Загрузить распакованное расширение»**, указав папку с `manifest.json`.
3. Откройте Liberty Wave → **«Источники» → «Создать код подключения»**.
4. Введите восьмизначный код в окне расширения. Код действует пять минут; соединение затем запоминается на этом компьютере.
5. Обновите уже открытые музыкальные вкладки и включите трек. Они появятся в списке с названием сервиса, браузера и трека.

Расширение рассчитано на актуальные браузеры Chromium 111+. Его Firefox-сборки пока нет; Firefox можно использовать через доступную системную медиасессию Windows. Управление сайтами использует Media Session и доступные элементы аудио/видеоплеера. Набор функций зависит от версии сайта. Перемешивание и повтор через расширение пока не предлагаются; в приложениях эти кнопки видны, если их поддерживает системная сессия.

Расширение связывается только с локальным виджетом. Доступ к содержимому страниц ограничен перечисленными музыкальными сервисами. Обложки запрашиваются с перечисленных CDN без cookies. Разорвать связь можно в окне расширения или через **«Отключить все браузеры»** в разделе «Источники» приложения. Подробности — [browser-extension/README.md](browser-extension/README.md).
