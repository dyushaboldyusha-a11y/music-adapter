# Music Adapter

Прозрачный настольный виджет для **установленного приложения Яндекс Музыки в Windows 10/11**. Тёмное стекло, красные акценты, обложка, прогресс и управление воспроизведением в стиле предоставленного референса.

## Использование

1. Откройте установленную Яндекс Музыку и включите трек.
2. Запустите `Music-Adapter-0.2.1-Windows.exe` из `release`, если приложение собрано, или `npm start` из исходников.
3. Виджет появляется в правом верхнем углу и пропускает клики в приложение под ним.
4. **Num8** на цифровом блоке при включённом **NumLock** включает управление. Курсор становится доступен в окне виджета; перетаскивайте за обложку, название или свободную область рамки.
5. Повторное **Num8** или **Esc** закрепляет виджет и возвращает пропуск кликов. Позиция сохраняется.

Резервное сочетание — **Ctrl+Shift+8**. Режим можно переключить нажатием на значок в системном трее. Если Num8 занят другой программой, виджет остаётся доступен для управления. В меню `…` и меню трея находятся непрозрачность, возврат в угол экрана и выход. Масштаб меняется через меню «…» (50–175%) или Ctrl + колесо мыши. Непрозрачность оформления регулируется от 25 до 100%; кнопки, название, исполнитель и шкала остаются непрозрачными. Под обложкой находится красная подпись Liberty. Волна сплошная и маской ограничена областью снаружи рамки. Внутри окна с активным управлением курсор отображается; виджет не изменяет курсор и режим ввода других приложений и игр.

## Связь с Яндекс Музыкой

Приложение читает **Windows Global System Media Transport Controls (GSMTC)** через встроенный Windows PowerShell 5.1. Выбирается только медиасессия с идентификатором Яндекс Музыки; другие плееры не получают команды. Браузерная вкладка Яндекс Музыки не является целью интеграции. Пароль, OAuth-токен, расширение браузера и изменение клиента Яндекс Музыки не нужны.

Название, исполнитель, обложка, состояние воспроизведения и прогресс обновляются из системной сессии. Пауза, предыдущий/следующий трек, перемотка, перемешивание и повтор включаются только тогда, когда клиент сообщает об их поддержке. Конкретный набор зависит от версии Яндекс Музыки. Недоступные через GSMTC кнопки скрыты. Лайки не предоставляются этим интерфейсом Windows, поэтому сердечка нет; добавить трек в любимое можно в Яндекс Музыке. Ошибки подключения не выводятся поверх виджета; состояние подключения доступно в меню.

Если подключение отсутствует, запустите трек в Яндекс Музыке, перезапустите оба приложения и убедитесь, что установлена актуальная версия официального клиента с поддержкой системных медиакнопок. Не запускайте приложения с разными уровнями привилегий. Виджет не требует прав администратора.

## Поверх окон

Используется прозрачное безрамочное Electron-окно с `alwaysOnTop`, пропуском мыши и глобальной клавишей Num8. Оно работает поверх обычных окон и обычно поверх игр в **безрамочном оконном режиме**. Windows не позволяет гарантировать показ обычного окна поверх эксклюзивного fullscreen, защищённого рабочего стола UAC, экрана блокировки или другого приложения, принудительно удерживающего верхний слой. Для игр используйте безрамочный режим. Внедрение в игры и обход античитов не используются.

### CS2 и 4:3

Виджет не меняет способ вывода CS2 в эксклюзивном полноэкранном режиме. Для надёжного показа поверх игры используйте **режим «В окне без рамки»**.

Чтобы сохранить 4:3 с растягиванием, сначала выставьте в Windows нужное разрешение 4:3 (например, 1280×960, если оно поддерживается), затем выберите в CS2 безрамочный режим. При необходимости включите растягивание на весь экран в настройках видеодрайвера. После выхода из игры разрешение рабочего стола можно вернуть.

Начиная с 0.2.1, виджет реагирует на смену разрешения, DPI, рабочей области и подключённых мониторов: возвращается в видимую область и повторно поднимается поверх окон без захвата клавиатурного фокуса. Если места мало, он временно уменьшает масштаб; после возврата разрешения восстанавливает выбранный размер. В меню трея доступно «Вернуть в угол экрана». Это исправляет потерю окна за краем экрана, но не добавляет поддержку эксклюзивного fullscreen.

## Разработка и сборка

Node.js 24.5+ и npm. Работа с Windows-сессией требует Windows 10 1809+ / Windows 11 и Windows PowerShell 5.1. Рекомендуется актуальная Windows 11; запускайте `check:windows` на целевой системе.

```sh
npm ci
npm start
npm test
npm run check:windows
npm run dist:win
```

Сборка создаёт переносимый Windows x64 `.exe` в `release/`; Node.js на компьютере пользователя не нужен. Приложение не подписано сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen. В репозитории есть Windows CI для проверки WinRT-моста и сборки. Конфигурация CI сама по себе не означает, что проверки уже выполнены.

```sh
npm run demo
```

Демо показывает пример After Dark с локальной иллюстрацией и явно обозначено внизу виджета. Оно не подключено к музыке и нужно для разработки интерфейса на Linux/macOS. Обычный запуск никогда не подменяет подключение демоданными. Демо-обложка — собственная иллюстрация, не обложка релиза.

В подготовленной облачной Linux-среде GUI можно проверить через Xvfb:

```sh
PATH=/workspace/.music-adapter-tools/x11/usr/bin:$PATH xvfb-run -a -s '-screen 0 1280x800x24 -nolisten tcp' npm run demo -- --disable-gpu
```

Проверки Node и интерфейса выполняются в Linux. Прямое управление установленной Яндекс Музыкой, Num8 в Windows и поведение поверх Windows-игр необходимо проверять на целевой машине.
