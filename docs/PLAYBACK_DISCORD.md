# Плавное воспроизведение и Discord

С версии 0.6.9 доступны плавный старт и пауза, а также музыкальный статус Discord. Оба переключателя находятся в разделе «Мой виджет».

## Плавный старт и пауза

Переключатель «Плавный старт и пауза» по умолчанию включён. При паузе громкость выбранного плеера затухает за 600 мс, затем воспроизведение останавливается и возвращается исходный уровень. При продолжении плеер запускается с нулевой громкости, которая плавно нарастает до прежней. Работают кнопки Wave, горячие клавиши и голосовые команды, в том числе «Вейв, пауза» и «Wave, resume».

Эффект применяется только при доступной управляемой громкости. Если плеер её не предоставляет, звук уже выключен или громкость равна нулю, работает обычная пауза. Переключатель сохраняется вместе с настройками и входит в профили приложений и экспорт оформления.

Для музыкальных вкладок обновите расширение из этой ветки и перезагрузите музыкальную страницу. Переход выполняется внутри вкладки, без передачи каждого шага через настольный мост. Предыдущие расширения продолжат работать с обычной паузой. Кнопки собственного интерфейса музыкального сервиса не запускают эффект Wave.

Команды выполняются последовательно. При смене источника переход отменяется, а громкость восстанавливается у исходного плеера. Обычное закрытие Wave также пытается восстановить громкость перед остановкой аудиомоста. Принудительное завершение процесса не позволяет гарантировать восстановление.

## Подключение Discord

Интеграция изначально выключена. Общий публичный Application ID Liberty Wave `1568620348604162058` уже встроен: пользователям не нужно создавать приложения Discord и вводить ID.

1. Запустите настольный Discord и разрешите показ активности в его настройках.
2. В Wave откройте «Мой виджет» → «Discord» и включите «Показывать музыку в Discord».

Бот, токен, Client Secret и вход в аккаунт через Wave не нужны. Веб-версия Discord не предоставляет локальный IPC. При необходимости своё приложение можно указать в закрытом по умолчанию блоке «Другое приложение Discord»: сохранённый ранее пользовательский ID сохраняется при обновлении. Чтобы вернуться к общему приложению, очистите поле и сохраните. Включение и выключение обычным переключателем не меняет сохранённый ID.

Wave передаёт название и исполнителя выбранного трека, доступную обложку и временные метки обычного воспроизведения. На паузе остаётся название с пометкой «На паузе», без бегущего времени. Для эфира, неизвестной длительности и изменённой скорости временные метки не показываются. Перемотка, смена трека и источника обновляют статус; изменения ограничены одним запросом в 15 секунд. Исчезновение источника и выключение интеграции очищают статус. После запуска или перезапуска Discord подключение повторяется автоматически.

С версии 0.7.1 обложка берётся по исходной HTTPS-ссылке музыкального сервиса, в том числе если ссылка появилась позже остальных данных трека. Если ссылки нет, для Яндекс Музыки сначала проверяется её публичный каталог, затем Apple Music/iTunes. Для остальных источников используется Apple Music/iTunes. Проверяются название и версия трека, исполнители, доступный альбом и длительность. Чужой трек с похожим названием не подходит.

Перед первым показом или заменой трека Wave ждёт обложку до 4 секунд; во время переключения предыдущий статус может кратко оставаться видимым. Название нового трека отправляется вместе с его найденной обложкой. Если каталог не ответил или точного совпадения нет, текстовый статус всё равно появляется. Поиск повторяется после сетевого сбоя, а кэш имеет ограниченный срок действия. Выключение интеграции отменяет поиск и повторные попытки; результаты старого трека не заменяют текущую обложку.

Discord принимает только публичную HTTPS-ссылку на картинку. Windows часто отдаёт локальную миниатюру без такой ссылки; если каталоги недоступны или трек в них отсутствует, обложку передать невозможно и Discord может показать значок приложения. Гарантировать обложку для произвольного локального файла без публичного размещения нельзя. Wave не загружает локальные изображения на сторонние серверы. Звук и микрофон для Discord не используются.

## Проверка

- `npm test`: воспроизведение, громкость, отмена, ошибки, источник и очередь; Discord RPC через реальные локальные сокеты (в Windows — именованные каналы), разделённые пакеты, ping/pong, переподключение, очистка и валидация обложек.
- `npm run test:playback` в Linux/Xvfb: настоящее окно Electron, промежуточные уровни громкости, переключатели, отмена перехода при выборе плеера, подключение одним переключателем с общим ID к тестовому серверу Discord RPC, сохранение пользовательского ID после перезапуска и возврат к общему ID. Поиск обложек заменён тестовым ответом, реальные учётные записи не используются.
- `npm run test:browser`: сквозная проверка Chromium MV3 ↔ Electron, включая плавный старт и паузу аудио в тестовых страницах пяти сервисов.
- Windows CI сохраняет проверки установщика, обновлений и упакованного голосового движка.

Общий Application ID проверяется через публичный API Discord. Для проверки отображения в настоящем профиле нужен запущенный настольный клиент с аккаунтом; автоматические тесты подтверждают протокол и поведение Wave на тестовом сервере.
