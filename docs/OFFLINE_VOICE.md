# Встроенные голосовые команды

С версии 0.6.6 Windows EXE содержит Vosk 0.3.45 и русскую модель
`vosk-model-small-ru-0.22`. В 0.6.7 добавлены английская модель
`vosk-model-small-en-us-0.15` и общий словарь из 116 фраз.
Русские и английские команды распознаются автоматически, без переключателя языка.
Устанавливать SAPI, речевые пакеты Microsoft, Python, драйверы или службы не нужно.
Интернет и дополнительные загрузки при первом запуске не требуются.
Две модели увеличивают размер загрузки по сравнению с 0.6.6 примерно на 40 МБ.

С версии 0.6.8 доступны активация по обращению Wave / вейв, точная громкость
и индикатор распознавания на самом виджете.

В «Мой виджет» → «Локальные голосовые команды» выберите режим
**«По слову Wave / вейв — без клавиши»**, микрофон и включите голосовое управление.
Произнесите обращение и команду одной фразой: «Вейв, следующий трек» или
«Wave, next». Горячая клавиша для этого режима не требуется.

Пока этот режим включён, микрофон открыт постоянно. Выключатель голосового
управления закрывает микрофон и отменяет ожидающие результаты. Обычная речь
и команды без обращения не управляют плеером. Одна фраза — одна команда;
дождитесь результата перед следующей. Максимальная длительность фразы — восемь
секунд. Звук обрабатывается в ограниченном буфере памяти на этом компьютере;
файлы со звуком и сетевые запросы распознавания не создаются.

Индикатор показывает ожидание Wave, прослушивание, обработку, услышанную фразу
и результат, например «вейв громкость тридцать процентов → Громкость 30%».
Если выбранный плеер не поддерживает действие, индикатор покажет ошибку.

Голос выключен по умолчанию. Выбранный режим и выключатель сохраняются после
перезапуска. Обновление сохраняет режим удержания у пользователей, которые
уже включили его в старой версии; для перехода выберите режим Wave один раз.
Режим удержания остаётся доступным: назначьте «Голос» в «Горячие клавиши»,
удерживайте сочетание, произнесите команду и отпустите. Микрофон этого режима
закрывается при отпускании, максимальное удержание — 15 секунд.

«Проверить микрофон» слушает выбранное устройство три секунды и показывает
результат без команд плееру. Проверка временно приостанавливает режим Wave;
через две секунды после результата он возобновляется, если голос включён.

## Точная громкость

Уровень меняется у выбранного плеера, в пределах 0–100%. Примеры для режима Wave:

- «Вейв, громкость тридцать процентов» — установить 30%.
- «Вейв, прибавь десять» — добавить 10 процентных пунктов.
- «Вейв, убавь десять процентов» — убрать 10 процентных пунктов.
- «Вейв, убавь вдвое» — уменьшить текущую громкость наполовину.
- «Вейв, сделай вдвое громче» — удвоить уровень, максимум до 100%.
- Wave, volume fifty percent.
- Wave, set volume to thirty five percent.
- Wave, lower volume by ten percent.
- Wave, halve volume.

Поддерживаются целые числа от нуля до ста на русском и английском. Значения
вне диапазона отклоняются. В режиме удержания и проверке микрофона обращение
Wave можно опустить.

Перед любой русской фразой или после неё можно сказать «пожалуйста»;
для английских фраз — please. В режиме Wave обращение ставится первым, а «пожалуйста» / please — после него или в конце команды. Например: «пожалуйста, следующий трек»,
volume up please. Стоп / stop ставит музыку на паузу. Выключение музыки означает
паузу, а выключение звука — mute. Команды сопоставляются целиком, а не по
наличию слова внутри произвольного предложения. Распознанные явные отрицания
«не …», do not и don't отклоняются. Неуверенные или противоречивые результаты
могут быть отклонены; тогда повторите команду отчётливо.

Проверка и голосовые команды используют выбранное устройство. Если Windows
запрещает доступ к микрофону, разрешите его для классических приложений в
настройках конфиденциальности.

## Сборка и проверка

Из корня репозитория на Node.js 24:

```sh
npm ci
npm run voice:prepare
npm run test:voice
npm run dist:win
```

`dist:win` и `pack:win` автоматически запускают подготовку голосовых данных.
Скрипт получает официальные архивы по HTTPS и проверяет закреплённые SHA-256
из `build/voice-assets.json` до распаковки. Загруженные архивы и подготовленные
данные находятся в игнорируемом `artifacts/`. Большие DLL и модели не записываются
в историю Git. Они включаются в EXE как `resources/native/voice/` вместе со
словарём `src/shared/voice-commands.json`. Интерфейс и нативный помощник используют
один словарь. Подготовка проверяет наличие моделей; нативная инициализация —
наличие всех слов команд в акустических словарях обеих моделей.

Для проверки в Linux можно подготовить дополнительную официальную библиотеку:

```sh
npm run voice:prepare -- --with-linux
pwsh -NoProfile -File native/windows-automation.ps1 -CheckSamples test/fixtures/voice
pwsh -NoProfile -File native/windows-automation.ps1 -CheckSamples test/fixtures/voice-wake
```

Проверка использует настоящий декодер, 51 прежний и 43 новых аудиопримеров, синтезированные русские и английские
команды, отрицания и посторонние фразы, тишину и шум. Windows CI повторяет её
для исходников, упакованного приложения и пути с кириллицей и пробелами.
Проверки Wave пропускают звук через тот же ограниченный буфер выделения фраз, что и постоянное прослушивание. Дополнительно проверяются все 202 соответствия чисел и отклонение похожих слов wait, wake, weave, «весь». SAPI и микрофон для этих тестов не используются. Результаты не заменяют
проверку человеческой речи на конкретном микрофоне.

Лицензии и сведения об исходных проектах находятся в `licenses/voice/` и
поставляются вместе с моделями. Vosk и обе модели распространяются по
Apache License 2.0; лицензии зависимостей сохранены отдельно.
