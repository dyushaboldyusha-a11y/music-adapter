# Встроенные русские голосовые команды

Начиная с 0.6.6, Windows EXE содержит Vosk 0.3.45 и русскую модель
`vosk-model-small-ru-0.22`. Устанавливать SAPI, речевые пакеты Microsoft,
Python, драйверы или службы не нужно. Для работы голоса не нужен интернет.
Модель увеличивает размер загрузки примерно на 60 МБ вместе с библиотеками.

В «Мой виджет» выберите микрофон и нажмите «Проверить микрофон».
Проверка длится три секунды и не выполняет команд плеера. Назначьте сочетание
«Голос» в «Горячие клавиши», включите голосовое управление, удерживайте
сочетание, произнесите команду и отпустите. Команды: «пауза», «продолжить»,
«следующий трек», «предыдущий трек», «громче», «тише», «выключить звук»,
«включить звук».

Микрофон закрывается при отпускании клавиши; затем распознаётся буфер в памяти.
Звук не записывается в файл и не отправляется в сеть. Проверка и голосовые
команды используют выбранное устройство. Если Windows запрещает доступ к
микрофону, разрешите его для классических приложений в настройках
конфиденциальности. Новый распознаватель не обходит эту системную настройку.

## Сборка и проверка

Из корня репозитория на Node.js 24:

```sh
npm ci
npm run voice:prepare
npm run test:voice
npm run dist:win
```

`dist:win` и `pack:win` автоматически запускают подготовку голосовых данных.
Скрипт получает официальные архивы по HTTPS и проверяет закреплённые SHA-256
из `build/voice-assets.json` до распаковки. Загруженные архивы и подготовленные
данные находятся в игнорируемом `artifacts/`. Большие DLL и модель не записываются
в историю Git. Они включаются в EXE как `resources/native/voice/`.

Для проверки в Linux можно подготовить дополнительную официальную библиотеку:

```sh
npm run voice:prepare -- --with-linux
pwsh -NoProfile -File native/windows-automation.ps1 -CheckSamples test/fixtures/voice
```

Проверка использует настоящий декодер: восемь синтезированных русских команд,
тишину и шум. Windows CI повторяет её для исходников, упакованного приложения
и пути с кириллицей и пробелами. SAPI и микрофон для этих тестов не используются.
Результаты не заменяют проверку человеческой речи на конкретном микрофоне.

Лицензии и сведения об исходных проектах находятся в `licenses/voice/` и
поставляются вместе с моделью. Vosk и русская модель распространяются по
Apache License 2.0; лицензии зависимостей сохранены отдельно.
