# Встроенные голосовые команды

С версии 0.6.6 Windows EXE содержит Vosk 0.3.45 и русскую модель
`vosk-model-small-ru-0.22`. В 0.6.7 добавлены английская модель
`vosk-model-small-en-us-0.15` и общий словарь из 116 фраз.
Русские и английские команды распознаются автоматически, без переключателя языка.
Устанавливать SAPI, речевые пакеты Microsoft, Python, драйверы или службы не нужно.
Интернет и дополнительные загрузки при первом запуске не требуются.
Две модели увеличивают размер загрузки по сравнению с 0.6.6 примерно на 40 МБ.

В «Мой виджет» выберите микрофон и нажмите «Проверить микрофон».
Проверка длится три секунды и не выполняет команд плеера. Назначьте сочетание
«Голос» в «Горячие клавиши», включите голосовое управление, удерживайте
сочетание, произнесите команду и отпустите. Полный список доступен в раскрывающемся
блоке «Команды и синонимы · русский / English».

## Все команды

| Действие | Русские команды | English |
| --- | --- | --- |
| Пауза | пауза, стоп, останови, остановить, останови музыку, остановить музыку, поставь на паузу, поставить на паузу, поставь паузу, выключи музыку | pause, stop, pause music, stop music, pause playback |
| Продолжить музыку | продолжить, продолжай, играй, играть, воспроизвести, включи музыку, включить музыку, запусти музыку, сними с паузы, снять с паузы | play, resume, continue, play music, resume music, start music |
| Следующий трек | следующий трек, следующий, следующая, следующая песня, дальше, вперёд, пропусти, пропустить, пропусти трек, переключи трек, переключить трек, включи следующий трек | skip, next, next track, next song, skip track, skip song, forward |
| Предыдущий трек | предыдущий трек, предыдущий, предыдущая, предыдущая песня, назад, верни трек, верни предыдущий трек, включи предыдущий трек | back, previous, previous track, previous song, go back, back track |
| Громче на 5% | громче, погромче, сделай громче, сделай погромче, прибавь громкость, увеличь громкость, увеличить громкость, добавь громкость, прибавь звук | louder, volume up, turn up, turn it up, increase volume, raise volume |
| Тише на 5% | тише, потише, сделай тише, сделай потише, убавь громкость, уменьши громкость, уменьшить громкость, убавь звук | quieter, volume down, turn down, turn it down, lower volume, decrease volume |
| Выключить звук | выключить звук, выключи звук, отключить звук, отключи звук, без звука, убери звук, звук выключи | mute, mute audio, mute sound, sound off, turn sound off |
| Включить звук | включить звук, включи звук, верни звук, вернуть звук, звук включи, восстановить звук | unmute, unmute audio, sound on, turn sound on, enable sound |

Перед любой русской фразой или после неё можно сказать «пожалуйста»;
для английских фраз — please. Например: «пожалуйста, следующий трек»,
volume up please. Стоп / stop ставит музыку на паузу. Выключение музыки означает
паузу, а выключение звука — mute. Команды сопоставляются целиком, а не по
наличию слова внутри произвольного предложения. Распознанные явные отрицания
«не …», do not и don't отклоняются. Неуверенные или противоречивые результаты
могут быть отклонены; тогда повторите команду отчётливо.

Микрофон закрывается при отпускании клавиши; затем распознаётся буфер в памяти.
Звук не записывается в файл и не отправляется в сеть. Проверка и голосовые
команды используют выбранное устройство. Если Windows запрещает доступ к
микрофону, разрешите его для классических приложений в настройках
конфиденциальности.

## Сборка и проверка

Из корня репозитория на Node.js 24:

```sh
npm ci
npm run voice:prepare
npm run test:voice
npm run dist:win
```

`dist:win` и `pack:win` автоматически запускают подготовку голосовых данных.
Скрипт получает официальные архивы по HTTPS и проверяет закреплённые SHA-256
из `build/voice-assets.json` до распаковки. Загруженные архивы и подготовленные
данные находятся в игнорируемом `artifacts/`. Большие DLL и модели не записываются
в историю Git. Они включаются в EXE как `resources/native/voice/` вместе со
словарём `src/shared/voice-commands.json`. Интерфейс и нативный помощник используют
один словарь. Подготовка проверяет наличие моделей; нативная инициализация —
наличие всех слов команд в акустических словарях обеих моделей.

Для проверки в Linux можно подготовить дополнительную официальную библиотеку:

```sh
npm run voice:prepare -- --with-linux
pwsh -NoProfile -File native/windows-automation.ps1 -CheckSamples test/fixtures/voice
```

Проверка использует настоящий декодер, синтезированные русские и английские
команды, отрицания и посторонние фразы, тишину и шум. Windows CI повторяет её
для исходников, упакованного приложения и пути с кириллицей и пробелами.
SAPI и микрофон для этих тестов не используются. Результаты не заменяют
проверку человеческой речи на конкретном микрофоне.

Лицензии и сведения об исходных проектах находятся в `licenses/voice/` и
поставляются вместе с моделями. Vosk и обе модели распространяются по
Apache License 2.0; лицензии зависимостей сохранены отдельно.
