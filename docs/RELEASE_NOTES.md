Liberty Wave 0.6.1 — надёжнее установка и очистка обновлений.

- Программа закрывается только после того, как установщик подтвердит проверку и подготовку новой версии. Если PowerShell не запустился, интерфейс остаётся открытым и показывает ошибку; сохраняются last-install.json и installer-start.log.
- После успешного обновления в той же папке появляется Liberty-Wave-<новая версия>-Windows.exe, а старый файл удаляется. При ошибке сохраняется/восстанавливается старая версия. Чужой файл с новым именем не перезаписывается.
- Устаревшие загрузки и прерванные части автоматически удаляются. Сохраняется одна актуальная копия, которую можно повторно использовать после проверки официальной контрольной суммы. Запущенный EXE и посторонние файлы не затрагиваются.
- Настройки, никнейм, бинды и подключения браузеров сохраняются. Расширение 0.6.0 совместимо; обновлять его ради этого исправления не требуется.

Если в 0.5.1/0.6.0 не сработала кнопка установки, один раз скачайте 0.6.1 вручную, полностью закройте старую программу и запустите новый EXE. Исправление находится в установщике нового приложения. Windows 10/11 x64.
