Liberty Wave 0.6.0 — персонализация и волна только от музыки.

- Никнейм до 12 символов вместо подписи Liberty; без регистрации и входа.
- Автоматические цвета из обложки и сохранённая ручная палитра.
- Плавное автоскрытие после паузы (5–600 секунд), возвращение при воспроизведении без перехвата фокуса. В режиме перемещения виджет остаётся видимым.
- Выбор монитора, привязка к краям, отступы 0–100 px и восстановление после отключения экрана.
- Конструктор: обложка, исполнитель и время включаются независимо в полном и компактном виде.
- Экспорт и импорт оформления, никнейма, горячих клавиш и положений в JSON. Токены и подключения браузеров не переносятся. Некорректный файл и занятые сочетания не заменяют действующие настройки.
- Для Windows-приложений волна читает только их аудиосессии, без общего звука устройства. Для вкладок используется отдельное разрешение расширения «Волна этой вкладки»; другие вкладки, игры и Discord не влияют. При недоступном источнике волна затухает.

Для браузерной волны обновите расширение до 0.6.0, перезагрузите музыкальную страницу, нажмите значок расширения на панели браузера и «Волна этой вкладки». Требуется Chromium 116+. Добавлены разрешения activeTab, tabCapture и offscreen; микрофон и запись аудио не используются.

С 0.5.1 доступно обновление через приложение после публикации релиза. Для 0.5.0 и старше один раз замените .exe вручную. Настройки сохраняются. Windows 10/11 x64.
