Liberty Wave 0.5.1 — исправление загрузки обновлений с GitHub.

- Исправлена ошибка «Нет соединения с GitHub» после нажатия «Скачать»: загрузчик теперь правильно обрабатывает перенаправления к файлам релиза в Electron.
- Адрес каждого перенаправления проверяется до загрузки. Проверки размера, SHA256 и формата Windows-приложения сохранены; отмена удаляет частично скачанные файлы.
- При реальной сетевой ошибке отображаются имя недоступного сервера и код ошибки, если он доступен.
- Сохранены отдельное окно Liberty Wave, настройки цвета, громкость, компактный режим, волна и все бинды версии 0.5.0.

**Для 0.5.0 и старше требуется однократная замена .exe вручную:** полностью закройте Liberty Wave, скачайте `Liberty-Wave-0.5.1-Windows.exe` и запустите его вместо прежнего файла. Настройки и подключения сохраняются. Исправление находится в самом загрузчике, поэтому старая версия не может скачать его через свою кнопку обновления.

Расширение 0.5.0 совместимо; переустанавливать его ради исправления обновлений не требуется. Windows 10/11 x64.
