Liberty Wave 0.6.2 — контраст светлого оформления и запуск виджета.

- Кнопки и включённые переключатели остаются различимыми при белом и светлом цвете оформления: внутренние элементы автоматически становятся тёмными. Для тёмных заливок используется светлый цвет. Состояние при наведении также учитывается.
- Исправлено обрезание закреплённого виджета при запуске с сохранённым масштабом. Масштаб содержимого применяется после загрузки страницы, до показа окна; нажимать бинд управления для восстановления отображения больше не требуется. Исправление действует в полном и компактном виде.
- Настройки, расположение, никнейм, цвет, подключения браузеров и горячие клавиши сохраняются. Ваш бинд управления не меняется. Расширения 0.6.0 и 0.6.1 совместимы; обновлять расширение ради этих исправлений не требуется.

Если установка из 0.5.1/0.6.0 закрывает приложение, но новая версия не появляется, один раз скачайте 0.6.2 вручную, нажмите «Завершить работу» в старом приложении и запустите новый EXE. Крестик только скрывает окно. Профиль настроек сохраняется. Windows 10/11 x64.
