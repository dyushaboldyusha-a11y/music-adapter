Liberty Wave 0.4.0 — новое имя и иконка, свои горячие клавиши и цвет интерфейса.

- Приложение переименовано в Liberty Wave. Новая чёрно-серебристая иконка встроена в Windows `.exe`, окно, трей и расширение.
- Настройки, бинды и подключения из прежнего профиля Music Adapter сохраняются.
- «…» → «Горячие клавиши…»: отдельные бинды для паузы/продолжения музыки и управления/закрепления виджета.
- По умолчанию Ctrl+Shift+8 переключает управление, Ctrl+Shift+Пробел — паузу/продолжение. NumPad не требуется; Num8 остаётся дополнительной клавишей для стандартной настройки управления.
- Горячая клавиша музыки работает в других приложениях и при закреплённом виджете, управляя выбранным источником. Наведение и клики по закреплённому виджету по-прежнему игнорируются.
- Запись клавиш временно отключает глобальные бинды; конфликты и одинаковые сочетания показываются в настройках. При ошибке прежняя настройка сохраняется. Настройки доступны через значок в трее.
- «…» → «Цвет интерфейса…»: круг оттенка/насыщенности, яркость, HEX и готовые цвета. Предпросмотр перекрашивает кнопки, волну, рамку, фон и панели; отмена возвращает прежнюю тему.
- Цвет и бинды сохраняются между запусками.

Закройте предыдущий виджет и запустите Liberty-Wave-0.4.0-Windows.exe. Уже установленное расширение 0.3.1 совместимо: для этих функций достаточно обновить приложение. Для новой установки рядом есть Liberty-Wave-Browser-Connector-0.4.0.zip.

Автоматические проверки воспроизводят глобальные клавиши при фокусе другого приложения, управление браузерным VK при закреплённом виджете, конфликты регистрации, палитру и перезапуск с сохранёнными настройками прежнего профиля. Отдельная проверка читает ресурсы Windows-файлов и подтверждает встроенные название и иконку. Проверки браузерных сервисов используют контролируемые страницы, не живые аккаунты. Windows x64; файл без сертификата издателя. Для игр требуется безрамочный режим.
