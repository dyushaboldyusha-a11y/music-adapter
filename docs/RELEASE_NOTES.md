Liberty Wave 0.6.10 — сохранение статуса Discord при переключении треков.

- Исправлена немедленная очистка статуса, когда плеер кратковременно отдаёт пустую медиасессию между песнями. Wave сохраняет прежнюю активность до 2,5 секунды, ожидая данные следующего трека.
- При реальном закрытии плеера статус очищается после этой задержки. Выключение интеграции по-прежнему очищает его сразу.
- Добавлена проверка перехода через пустую медиасессию к следующему треку без отправки пустого статуса Discord.

В 0.6.4–0.6.9 доступно встроенное обновление. Настройки, бинды и подключения сохраняются.
