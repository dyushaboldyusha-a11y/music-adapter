Liberty Wave 0.4.1 — бинды переключения треков и обновления из приложения.

- В «Горячие клавиши…» добавлены отдельные бинды «Следующий трек» и «Предыдущий трек». Они работают при фокусе игры/другого приложения и закреплённом виджете, управляя выбранным источником.
- Новые бинды сначала не назначены. Старые сочетания, тема, размер и подключение браузера сохраняются. Кнопка × отключает отдельный музыкальный бинд.
- «Обновления Liberty Wave…»: проверка GitHub-релиза, скачивание с прогрессом, SHA-256, установка на месте прежнего .exe и перезапуск виджета.
- При неверной контрольной сумме приложение не заменяется. Установщик сохраняет резервную копию до завершения замены и защищает занятый файл.

**С версии 0.4.0 и старше один раз обновитесь вручную:** закройте старый виджет и замените его файлом Liberty-Wave-0.4.1-Windows.exe. В уже опубликованной 0.4.0 кнопки обновления нет. Последующие обновления можно будет устанавливать через меню приложения. Новая программа и повторная настройка не требуются. Уже установленное расширение 0.3.1/0.4.0 совместимо; для новой установки рядом есть Liberty-Wave-Browser-Connector-0.4.1.zip.

Установка из приложения поддерживается в переносимой Windows-сборке, из доступной для записи папки. Сохраняется прежний путь запуска, даже если имя .exe содержит старый номер версии; установленная версия указана в меню обновлений. Музыкальный плеер продолжает играть, перезапускается только виджет.

Проверки воспроизводят клавиши следующего/предыдущего трека, точную маршрутизацию вкладок, миграцию настроек 0.4.0, сетевую загрузку и SHA-256. Windows-проверка устанавливает обновление на место тестового файла и проверяет отказ при неверной сумме и блокировке. Браузерные проверки используют контролируемые страницы, не живые аккаунты. Windows x64; файл без сертификата издателя. Для игр требуется безрамочный режим.
