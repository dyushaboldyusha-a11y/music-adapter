Music Adapter 0.2.1 — исправление размещения при смене разрешения.

- Виджет теперь реагирует на смену разрешения, DPI и рабочей области, включая переходы на 1280×960, 1024×768 и другие 4:3.
- Окно возвращается в видимую область и повторно поднимается поверх обычных окон без захвата клавиатурного фокуса.
- На маленьком экране масштаб временно уменьшается; выбранный пользователем размер восстанавливается после возврата разрешения.
- Сохранены Liberty, выборочная прозрачность 25–100%, масштабирование, обложки и внешняя сплошная волна.

Для показа поверх CS2 используйте безрамочный оконный режим. Для растянутого 4:3 можно предварительно выставить такое же разрешение в Windows и включить нужное масштабирование видеодрайвера. Исправление размещения не позволяет обычному Electron-окну отображаться поверх эксклюзивного fullscreen или защищённых экранов Windows. В самой CS2 сборка не проверялась.

Num8 включает управление, повторное нажатие закрепляет виджет. Исполняемый файл не подписан сертификатом издателя.

Скачайте Music-Adapter-0.2.1-Windows.exe в Assets. Рядом находится SHA256SUMS.txt.
