Music Adapter 0.2.0 — Liberty, виджет Яндекс Музыки для Windows x64.

- Красная подпись Liberty под обложкой.
- Масштаб 50–175%: меню «…» или Ctrl + колесо мыши при включённом управлении.
- Непрозрачность оформления 25–100%. Кнопки, название, исполнитель и шкала остаются чёткими.
- Сплошная плавная красная волна, ограниченная внешней областью рамки.
- Убраны всплывающие ошибки поверх виджета, сердечко и недоступные в медиасессии кнопки.
- Чтение обложки отделено от метаданных: ошибка картинки не должна сбрасывать трек. Добавлено распознавание форматов по байтам и повторная загрузка после ошибки.

Num8 включает управление и перетаскивание; повторное нажатие закрепляет виджет и пропускает клики сквозь него. NumLock должен быть включён. Настройки и положение сохраняются.

Проверки Windows включают чтение настоящего WinRT-потока изображения и обмен сообщениями с медиамостом. Подключение к конкретной версии установленной Яндекс Музыки требует проверки на пользовательской машине; без предоставленной приложением обложки виджет не подменяет её демонстрационной. Для игр используйте безрамочный режим. Исполняемый файл не подписан сертификатом издателя.

Скачайте Music-Adapter-0.2.0-Windows.exe в Assets. Рядом находится SHA256SUMS.txt.
