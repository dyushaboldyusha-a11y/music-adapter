Music Adapter 0.1.0 — виджет Яндекс Музыки для Windows x64.

- Прозрачное окно поверх обычных приложений с красными светящимися волнами по краям.
- Num8 включает управление и перетаскивание; повторное нажатие закрепляет виджет и включает пропуск кликов. NumLock должен быть включён.
- Связь с медиасессией установленной Яндекс Музыки; доступность отдельных команд зависит от клиента.
- Переносимый exe, установка Node.js не требуется.

Сборка и проверка обмена сообщениями с системным медиамостом выполняются на Windows в GitHub Actions перед публикацией. Реальное управление установленной Яндекс Музыкой и поведение поверх игр требуют проверки на пользовательской машине. Для игр используйте безрамочный режим: эксклюзивный fullscreen и защищённые экраны Windows не поддерживаются. Исполняемый файл не подписан сертификатом издателя.

Скачайте `Music-Adapter-0.1.0-Windows.exe` в разделе Assets. Контрольная сумма SHA-256 опубликована в `SHA256SUMS.txt`.
