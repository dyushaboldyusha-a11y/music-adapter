Liberty Wave 0.6.6 — русский голосовой ввод сразу после установки.

- В EXE встроены локальный движок Vosk и русская модель. SAPI, отдельные речевые пакеты Microsoft, Python и установка компонентов Windows больше не требуются.
- Все восемь команд работают на русском: «пауза», «продолжить», «следующий трек», «предыдущий трек», «громче», «тише», «выключить звук», «включить звук».
- Сохранены выбор микрофона и трёхсекундная проверка уровня и распознавания. Проверка не управляет музыкой. Микрофон используется только при удержании клавиши или по явному нажатию проверки.
- Распознавание выполняется без интернета. Звук обрабатывается в памяти, не сохраняется в файл и не отправляется на сервер. Разрешение Windows на доступ к микрофону по-прежнему необходимо.
- Модель и библиотеки включены в EXE; дополнительных загрузок при первом запуске нет. Размер приложения увеличился. Лицензии сторонних компонентов поставляются вместе с ними.
- Сборка проверяет SHA-256 официальных архивов. CI распознаёт восемь русских аудиопримеров, отклоняет тишину и шум и повторяет проверку для упакованного приложения и пути с кириллицей.

В 0.6.4–0.6.5 можно использовать встроенное обновление. С 0.6.1–0.6.3 полностью завершите старую версию и вручную запустите новый EXE. Настройки, бинды и подключения сохраняются.
