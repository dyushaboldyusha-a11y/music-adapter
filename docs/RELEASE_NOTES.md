Liberty Wave 0.5.0 — громкость, компактный режим и волна в такт звуку.

- Ползунок громкости и отключение звука у выбранного плеера. Для Windows-приложений используется их отдельная аудиосессия; общая громкость Windows не меняется.
- Отдельные бинды увеличения/уменьшения громкости на 5%, отключения звука и компактного режима. Назначаются в «Горячие клавиши…»; список можно прокручивать. Прежние клавиши сохраняются, новые сначала не назначены.
- Компактная полоска с обложкой, названием, исполнителем, транспортом, прогрессом и громкостью. Масштабирование и закрепление продолжают работать; положения двух видов сохраняются отдельно. Настройки временно разворачивают карточку.
- «Волна и свечение…»: реакция на фактический уровень всего звука устройства вывода Windows по умолчанию, декоративная анимация или выключение. Интенсивность 0–100%, экономичный режим 12 кадров/с вместо 30. В тишине свечение затухает. Микрофон не используется, аудиозапись не создаётся; контур остаётся непрерывным снаружи карточки.
- Палитра, прозрачность оформления, браузерные подключения и установленные бинды сохраняются.

**Для громкости музыкальных вкладок обновите расширение до 0.5.0 и перезагрузите страницы.** Регулятор виден, когда сайт предоставляет доступ к аудио/видеоплееру или поддерживаемому API VK. Текст Media Session сам по себе не даёт управлять громкостью. Без расширения системная медиасессия браузера не позволяет менять звук отдельной вкладки.

Из 0.4.1 можно обновиться через «…» → «Обновления Liberty Wave…». Для 0.4.0 и старше один раз замените .exe вручную, закрыв старый виджет. Путь к настройкам не меняется. Windows x64; для игр требуется безрамочный режим.

Проверки интерфейса и расширения используют Electron/Chromium с контролируемыми музыкальными страницами; живые аккаунты не используются. Устройство вывода и приложения с собственным выводом на другое устройство могут не предоставлять подходящую аудиосессию — в таком случае неработающие регуляторы скрываются.
