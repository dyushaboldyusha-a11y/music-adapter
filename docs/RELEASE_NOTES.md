Music Adapter 0.3.0 — Liberty: приложения и музыкальные вкладки.

- В закреплённом режиме кнопки не реагируют на движения мыши, наведение, фокус и клики. Num8 возвращает управление.
- Новый список источников с автоматическим и ручным выбором. Закрытие вручную выбранного источника не отправляет команды другому плееру.
- Windows-медиасессии Яндекс Музыки, Spotify, SoundCloud-совместимых клиентов и поддерживаемых браузеров.
- Расширение для точного подключения вкладок Яндекс Музыки, Spotify, SoundCloud, YouTube / YouTube Music и VK Музыки.
- Единый GUI с названием сервиса и браузера, обложкой и доступными кнопками; поддержка живого эфира и длинных видео.
- Сохранены Liberty, внешняя сплошная волна, прозрачность 25–100%, масштаб и исправление позиции при смене разрешения.

Скачайте **Music-Adapter-0.3.0-Windows.exe**. Для точного выбора музыкальных вкладок также скачайте **Liberty-Browser-Connector-0.3.0.zip**. Распакуйте архив, загрузите его через режим разработчика на странице расширений Chrome / Edge / Яндекс Браузера, затем в виджете откройте меню «…» → «Подключить браузер» и введите код в расширение. Обновите музыкальные вкладки после установки. Подробная инструкция находится внутри архива и в README репозитория.

Пароли музыкальных аккаунтов не нужны. Доступность команд и обложек зависит от приложения и сайта. SoundCloud-клиент / PWA должен предоставлять системную медиасессию; иначе используйте браузерное расширение. Firefox доступен через системную сессию; Firefox-сборки расширения пока нет. Проверки Chromium используют контролируемые страницы с реальными API браузера, а не живые аккаунты сервисов.

Для CS2 и других игр нужен безрамочный режим: эксклюзивный fullscreen не поддерживается. Windows x64, исполняемый файл без сертификата издателя. Контрольные суммы находятся в SHA256SUMS.txt.
