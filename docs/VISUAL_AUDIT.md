# Визуальная проверка Liberty Wave

Проверка выполнена в настоящем Electron после версии 0.7.1. Изменения находятся в ветке `fix/visual-interface-audit`.

Проверены все пять разделов приложения, размеры 1000×800, 851×540 и 760×540, прокрутка, раскрытые настройки Discord и голоса, профили, длинные строки, состояния обновления и ошибки. Для виджета проверены полный и компактный режимы, полоски ритма, масштаб 50/100/175%, отсутствие плеера, восстановление подключения, пауза, mute, скрытие элементов и светлые/тёмные обои. Отдельный тест запуска проверяет 36 сочетаний масштаба, DPI 100/125/150% и режима виджета.

| Найденный дефект | Исправление |
| --- | --- |
| Время компактного виджета перекрывало нижние подписи | Время перенесено из фиксированного наложения в обычную раскладку; длинный источник сокращается раньше остальных элементов |
| Нижняя строка виджета терялась на обоях противоположного цвета | Добавлена тонкая стеклянная подложка |
| При 25% непрозрачности светлый текст/иконки терялись на светлом фоне, тёмные — на тёмном | Под текстом сохраняется единая подложка карточки; обложка, блики, рамка и волна по-прежнему приглушаются выбранной непрозрачностью |
| Без плеера оставались пустая капсула кнопок и шкала | Показано состояние ожидания; управление возвращается при подключении |
| Белый акцент скрывал клавиатурный фокус виджета на светлом стекле | Рамка использует читаемый оттенок акцента |
| Длинный профиль залезал под «Удалить» и создавал горизонтальную прокрутку | Добавлен перенос текста; кнопка сохраняет размер |
| Длинное сочетание клавиш обрезало название самой клавиши | Сочетание полностью переносится по разделителям; добавлена подсказка |
| Длинное название источника выходило из колонки к кнопкам | Добавлены сокращение с многоточием и подсказка с полным названием |
| Фокус «Вернуть виджет на экран» превращался в линию над строкой | Рамка перенесена внутрь карточки и скруглена |
| Дорожка яркости оставалась незаполненной при любом значении | Заполнение синхронизировано со значением, сменой цели палитры и отменой |
| Красные ошибки были плохо читаемы на розовом и сером стекле | Цвет ошибки адаптируется к палитре; контраст проверяется на 256 серых и насыщенных цветах |
| Значки сервисов были бледными, а эмодзи SoundCloud/YouTube/Connector зависели от системы | Использованы единообразные векторные значки на контрастных подложках |
| В расширении текст кнопок терял контраст при наведении | Исправлены основной и вторичный варианты; добавлены различимые фокус и отключённое состояние |
| Кнопки запуска/остановки волны в расширении слипались | Добавлен отступ 8 px |
| Длинная ошибка или URL расширения обрезались по ширине | Добавлен перенос без горизонтального переполнения |

Выбранные цвета и сохранённое значение непрозрачности не заменяются. Изменена отрисовка подложки виджета, чтобы декор мог затухать независимо от читаемости текста и управления.

Проверки:

- `npm test` — 158 тестов, включая контраст ошибок и прежние проверки поведения.
- `npm run test:visual-audit` — реальные окна приложения и popup расширения, контраст, длинные строки, фокус и геометрия. Неизменённая опубликованная 0.7.1 проваливает 20 проверок.
- `npm run test:widget-visual` — раскладка времени и нижней строки, отключение/восстановление источника, снимки на чёрной/белой подложке, непрозрачность 25% и фокус при белом акценте. Старая 0.7.1 не проходит проверку компактной раскладки.
- Существующие проверки `test:gui`, `test:control`, `test:features`, `test:personalization`, `test:startup`, `test:music-effects`, `test:glass` и `test:glass-fixes` проверяют сохранение поведения и предыдущих визуальных исправлений.

Снимки и измерения сохранены в `artifacts/control-visual-audit-after/`, `artifacts/visual-audit-regression/` и `artifacts/widget-visual/`. Эти локальные артефакты не входят в Git.

Проверка выполнялась в Linux/Electron. Недоступные здесь состояния Windows воспроизведены через тестовые снимки состояния. Фактическая системная отрисовка DWM и поведение установленного Windows-клиента в этом прогоне не проверялись. Новые тесты также подключены к Windows CI для следующего запуска.
