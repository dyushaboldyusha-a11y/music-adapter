# Liberty Wave: музыкальные вкладки

Расширение для актуальных Chrome, Edge и Яндекс Браузера (Chromium 116+). Поддерживает страницы Яндекс Музыки, Spotify, SoundCloud, YouTube / YouTube Music и VK Музыки.

1. Распакуйте архив расширения в постоянную папку.
2. Откройте страницу расширений своего браузера (`chrome://extensions`, `edge://extensions` или `browser://extensions`). Включите режим разработчика и нажмите «Загрузить распакованное расширение», указав эту папку.
3. Откройте приложение Liberty Wave → «Источники» → «Создать код подключения».
4. Нажмите значок расширения и введите показанный виджетом восьмизначный код.
5. После установки или обновления расширения перезагрузите музыкальные вкладки, включите трек и выберите источник в разделе «Источники» приложения. Либо оставьте «Автоматически».

Пароли и токены музыкальных сервисов не нужны. Вход в сервис выполняется на его обычном сайте. Расширение читает состояние Media Session / аудио- и видеоплеера только на перечисленных сайтах и передаёт его виджету на этом компьютере. Обложки загружаются с разрешённых CDN без передачи cookies; доступность некоторых обложек зависит от сервиса.

Кнопки предлагаются только при наличии обработчика Media Session, доступного аудио/видео или подходящей кнопки сайта. Функции могут зависеть от браузера и версии сайта. После изменения сайта адаптер может потребовать обновления. Firefox-версия расширения в этот архив не входит; Firefox можно выбирать через системную медиасессию Windows, если она доступна.

Чтобы разорвать подключение, нажмите «Отключить браузер» в расширении либо «Отключить все браузеры» в разделе «Источники» приложения Liberty Wave. Закрытые вкладки исчезают из списка; вручную выбранный закрытый источник не заменяется другим плеером.

### Громкость в 0.5.0

Обновите расширение и перезагрузите музыкальные вкладки. Виджет передаёт громкость и mute выбранному HTML-аудио/видеоэлементу, включая созданные вне DOM `new Audio()`. Для VK с приватным плеером используются `getVolume` / `setVolume`, только если они доступны. Если есть лишь текст Media Session, регулятор скрывается. Старая версия расширения продолжит передавать треки и транспорт, но для новых команд громкости нужна 0.5.0.

### Волна только от музыкальной вкладки (0.6.0)

Откройте нужную музыкальную страницу, нажмите значок расширения на панели браузера и «Волна этой вкладки». Доступ выдаётся после этого действия пользователя. Новые разрешения activeTab, tabCapture и offscreen нужны для измерения именно её звука; микрофон не используется. Звук не записывается и не отправляется в интернет: только уровень передаётся виджету на 127.0.0.1.

Захват отключает прямой звук вкладки, поэтому расширение воспроизводит его через AudioContext в offscreen-документе. При остановке волны или закрытии/перезагрузке страницы восстанавливается обычный вывод браузера. Одновременно анализируется одна вкладка; виджет использует её уровень только когда выбран именно этот источник. Для другой вкладки включите её волну отдельно. Уровни передаются с частотой до 10 Гц; отрисовка виджета сглаживается до 30 или 12 кадров/с.
